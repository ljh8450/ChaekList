# Frontend Change Skill

Use this skill when a task mainly affects the React frontend.

## Workflow
1. Read relevant files in `frontend/`.
2. Read `docs/design-concept.md` before making UI or styling changes.
3. Follow existing UI, styling, and state-management patterns.
4. Make the smallest safe change.
5. Run frontend validation commands if available.
6. Report changed files and validation results.

## Constraints
- Do not edit backend files unless required.
- Reuse existing components and hooks where possible.
- Design UI and styling changes to match the direction, tone, layout principles, and component guidance in `docs/design-concept.md`.
