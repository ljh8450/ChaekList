# ChaekList

ChaekList는 수험서, 문제집, 전공서가 섞인 기존 베스트셀러 목록에서 벗어나
진짜 읽을 만한 교양서를 빠르게 발견하도록 돕는 독서 플랫폼입니다.

## 서비스 개요

**한 줄 정의**

수험서와 전공서를 제거하고, 교양 독서에 적합한 책만 추천해주는 독서 플랫폼

**핵심 가치**

- 기존 베스트셀러는 수험서, 문제집, 전공서가 함께 섞여 있어 실제 독서 목적에 맞는 책을 찾기 어렵습니다.
- ChaekList는 교양 독서 전용 필터링과 트렌드 분석을 통해 읽을 만한 책을 더 빠르게 보여줍니다.
- 로그인하지 않은 사용자도 홈에서 현재 인기 있는 책과 급상승 흐름을 바로 확인할 수 있습니다.

## 페르소나

**김민준, 24세**

- 리디북스, 밀리의서재 등 E-book 중심으로 독서합니다.
- 자기계발, 교양, 인문 분야에 관심이 많습니다.
- 책을 읽는 시간보다 "무엇을 읽을지" 고민하는 시간이 더 깁니다.

**Pain Point**

- 베스트셀러 목록에 수험서, 자격증 책, 전공서가 섞여 있어 실제로 읽을 책을 찾기 어렵습니다.
- 요즘 사람들이 어떤 책을 읽는지 알고 싶지만, 판매량 중심 순위만으로는 독서 트렌드를 파악하기 어렵습니다.

**Needs**

- 교양 책만 따로 보고 싶습니다.
- 나에게 맞는 책을 추천받고 싶습니다.
- 요즘 많이 읽히는 책과 키워드 트렌드를 알고 싶습니다.

## 문제 정의

기존 베스트셀러는 대부분 판매량 기반으로 제공되기 때문에 사용자의 독서 목적을 충분히 반영하지 못합니다.
플랫폼마다 랭킹 기준이 다르고, 교양 독서용 책과 공부용 책을 명확히 구분하지 않습니다.

결과적으로 사용자는 읽을 책을 고르는 과정에서 피로감을 느끼게 됩니다.

## 핵심 해결책

ChaekList는 다음 세 가지 기능을 중심으로 문제를 해결합니다.

### 1. 교양 전용 랭킹

수험서, 문제집, 전공서를 자동으로 제거하고 교양 독서에 적합한 책만 랭킹으로 제공합니다.

주요 카테고리:

- 인문
- 자기계발
- 경제
- 소설
- 에세이

목표는 "진짜 읽을 책 순위"를 제공하는 것입니다.

### 2. 개인 맞춤 추천

사용자의 관심 분야, 읽은 책, 유사한 사용자 행동을 기반으로 개인화된 추천을 제공합니다.

추천 기준:

- 관심 분야 기반 추천
- 읽은 책 기반 추천
- 비슷한 유저 기반 추천

목표는 사용자가 "나에게 맞는 책"을 빠르게 발견하도록 돕는 것입니다.

### 3. 트렌드 피드

요즘 많이 읽히는 책, 급상승 책, 특정 키워드 기반 트렌드를 피드 형태로 제공합니다.
로그인하지 않은 사용자에게도 현재 인기 있는 책을 먼저 보여주고, 로그인 후에는 개인 관심 분야를 반영한 추천으로 확장합니다.

예시 키워드:

- 도파민
- 투자
- AI

목표는 "사람들이 요즘 읽는 책"을 보여주는 것입니다.

## 핵심 기능 상세

### 교양 필터링 시스템

ChaekList의 핵심은 교양이 아닌 책을 제거하는 필터링 엔진입니다.

필터링 방식:

- 키워드 기반 필터링: 기출, 문제집, 수능, 기사, 전공 등
- 카테고리 기반 제거
- 향후 ML 기반 분류로 확장

### 랭킹 시스템

단순 판매량이 아니라 실제로 읽히고 탐색되는 데이터를 반영합니다.

랭킹 요소:

- 조회수
- 클릭률
- 저장 또는 찜 수
- 리뷰 수
- 최근 상승률

### 추천 시스템

초기 MVP에서는 콘텐츠 기반 추천으로 시작하고, 이후 협업 필터링으로 확장합니다.

초기 추천:

- 장르 기반 추천
- 키워드 기반 추천

확장 추천:

- 협업 필터링
- 유사 유저 클러스터링

### 피드 UI

사용자가 자연스럽게 책을 탐색할 수 있도록 피드형 UI를 제공합니다.

피드 구성:

- 급상승
- 오늘의 추천
- 테마 큐레이션

비로그인 사용자는 홈에서 전체 인기 책과 급상승 책을 볼 수 있고, 로그인 사용자는 개인화된 오늘의 추천을 함께 볼 수 있습니다.
