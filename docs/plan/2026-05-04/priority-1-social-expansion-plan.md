## 현재 정책 기준

### 공개 범위

- 사용자가 직접 공개한 게시글만 공개 피드와 검색에 노출한다.
- 공개 게시글이 있으면 별도 공개 프로필 설정 행이 없어도 공개 프로필 접근을 허용한다.
- 비공개 게시글은 feed/search/public profile에서 제외한다.
- 비활성화 계정의 공개 게시글은 숨긴다.
- 탈퇴 계정의 기존 공개 게시글은 삭제하지 않고 작성자 정보를 익명화한다.

### 대표 배지

- 대표 배지는 `badgesVisibility = PUBLIC`일 때만 공개 화면에 노출한다.
- 노출 위치:
  - 공개 피드 사용자명 앞
  - 공개 프로필 사용자명 앞
  - 공개 유저 검색 사용자명 앞
- 대표 배지명은 공개 유저 검색 조건에 포함하지 않는다.

### moderation

- 1차는 사용자 신고 기반 수동 처리다.
- 부적절한 닉네임은 사용자 신고에 따라 처리한다.
- 반복 게시 수량 제한은 두지 않는다.
- 생성/좋아요/추천 저장 등 주요 요청은 멱등성을 보장한다.

## 남은 SNS 확장 계획

### 1. 공개 프로필 확장

목표:

- 공개 프로필을 단순 요약이 아니라 유저별 공개 활동 허브로 만든다.

작업:

- `GET /api/users/{userId}/social/posts` 후보 검토
- 공개 프로필 화면에 공개 게시글 목록 추가
- 공개 프로필 화면에 게시글 타입 필터 추가
- 공개 게시글 수, 최근 활동일, 대표 배지, 공개 관심 분야 표시 정책 정리
- 숨김/비활성/탈퇴 정책을 feed/search와 동일하게 적용

검증:

- 공개 게시글만 보이는지 확인
- 비공개 게시글 미노출 확인
- 숨김 게시글 미노출 확인
- 탈퇴 유저 익명 게시글의 프로필 연결 처리 확인

### 2. 공개 유저 검색 결과 개선

현재 검색 조건:

- 닉네임
- 공개 게시글 내용
- 공개 게시글의 책 제목/저자
- 공개 게시글 타입
- 공개 관심 분야

남은 작업:

- 검색 결과 summary 개선
  - 공개 게시글 수
  - 공개 관심 분야 일부
  - 최근 공개 활동일
- 정렬 점수 보정
  - 닉네임 직접 매칭 우선
  - 최근 공개 활동 보조
  - 공개 게시글 수 보조
- 검색 성능 점검
  - `social_posts.user_id`
  - `social_posts.visibility/status`
  - `user_interest_categories.user_id`
  - `categories.name`

제외:

- 대표 배지명 검색
- 비공개 관심 분야 검색
- 비공개 게시글 검색

### 3. 공개 피드 개선

작업:

- 피드 정렬 옵션 추가
  - 최신순
  - 좋아요 많은 순
- 피드 타입 필터 정리
  - 전체
  - 자유 글
  - 책 공유
  - 성장 카드
  - 추천 공유
- 차단 유저 게시글 숨김 상태 UX 개선
- 신고 후 클라이언트에서 즉시 숨김 처리

주의:

- 추천형 피드는 후순위다.
- 공개 범위 정책을 바꾸지 않는다.

### 4. SNS 활동 기반 성장 점수 보정

현재 반영:

- 활성 게시글 최대 5개까지 개당 2점
- 받은 좋아요 최대 5개까지 개당 1점
- 삭제/숨김 게시글 제외

남은 결정:

- 월간 활동만 반영할지 여부
- 본인 좋아요 제외 여부
- 점수 상한 유지 여부
- UI에서 SNS 활동 반영을 설명할지 여부

권장:

- 독서 성장의 핵심 점수는 독서 활동 중심으로 유지한다.
- SNS 활동은 보조 점수로 유지한다.

### 5. 미디어 첨부

작업:

- 이미지 첨부 정책 수립
- 첨부 파일 개수 제한
- 첨부 파일 크기 제한
- MIME type 검증
- 저장소 결정
- 썸네일 생성 여부 결정
- 신고/숨김 정책과 연결

후순위:

- 영상 첨부
- 미디어 자동 moderation

### 6. 알림

작업:

- 서버 저장형 알림 목록
- 좋아요 알림
- 신고 처리 상태 알림
- 읽음 처리

후순위:

- 실시간 push
- 이메일 알림

### 7. 관리자 moderation 도구

작업:

- 신고 목록
- 신고 상세
- 게시글 숨김/해제
- 닉네임 신고 처리
- 운영자 메모
- 반복 신고 남용 방지
