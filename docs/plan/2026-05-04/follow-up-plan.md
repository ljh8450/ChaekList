## 남은 우선순위

### 1. 공개 프로필 콘텐츠 확장

목표:

- 공개 프로필이 단순 요약 화면이 아니라 유저 탐색의 도착지 역할을 하도록 만든다.

구현 후보:

- 공개 프로필에서 해당 유저의 공개 게시글 목록 조회
- 공개 프로필에서 좋아요가 많은 공개 게시글 표시
- 공개 독서 통계 요약 표시
  - 공개 설정을 따른 읽은 책 수
  - 공개 설정을 따른 관심 분야
  - 공개 설정을 따른 대표 배지
- 공개 프로필에서 게시글 필터 제공
  - 전체
  - 자유 글
  - 책 공유
  - 성장 카드

주의:

- 비공개 독서 기록, 비공개 관심 분야, 비공개 배지는 노출하지 않는다.
- 탈퇴 또는 비활성화 유저의 프로필 접근 정책을 기존 feed/search 정책과 일치시킨다.

### 2. 공개 유저 검색 탐색성 추가 보강

현재 반영된 범위:

- 닉네임
- 공개 게시글 내용
- 공개 게시글과 연결된 책 제목/저자
- 공개 관심 분야

추가 확장 후보:

- 공개 프로필 요약 문구 검색
- 공개 게시글 최신 활동일 기반 정렬 보정
- 공개 게시글 수와 최근 활동을 함께 반영한 랭킹 점수
- 유저 검색 결과 summary 개선
  - 공개 게시글 수
  - 최근 공개 활동
  - 공개 관심 분야 일부

제외 유지:

- 대표 배지명은 유저 검색 조건에 넣지 않는다.
- 비공개 관심 분야와 비공개 게시글은 검색 조건에 넣지 않는다.

### 3. 공개 피드 품질 개선

구현 후보:

- 피드 정렬 옵션
  - 최신순
  - 좋아요 많은 순
  - 내 관심 분야와 가까운 순
- 피드 타입 필터 고도화
  - 자유 글
  - 책 공유
  - 성장 카드
  - 추천 공유
- 차단 유저 게시글 숨김 상태의 UX 개선
- 신고 후 해당 게시글을 즉시 숨기는 클라이언트 상태 처리

주의:

- 1차는 공개 SNS의 안정성이 우선이므로 추천형 피드 랭킹은 과도하게 복잡하게 만들지 않는다.

### 4. SNS 활동 점수 보정

현재 반영:

- 활성 게시글 최대 5개까지 개당 2점
- 받은 좋아요 최대 5개까지 개당 1점
- 삭제/관리자 숨김 게시글 제외

확장 후보:

- 월간 SNS 활동만 반영할지, 누적 활동을 반영할지 정책 결정
- 본인 좋아요를 받은 좋아요 점수에서 제외할지 결정
- 반복 게시로 점수만 올리는 행위를 막기 위한 상한 유지
- 레벨 진행률 설명에 SNS 활동 반영 여부를 표시할지 결정

권장:

- 당장은 보조 점수로 유지한다.
- 독서 성장의 핵심 점수는 읽기, 저장 후 읽음, 분야 다양성, 추천 전환에 둔다.

### 5. 미디어 첨부 확장

현재 범위:

- 자유 텍스트는 1차에 포함됐다.
- 이미지/영상 첨부는 미구현이다.

확장 계획:

- 이미지 첨부부터 시작한다.
- 파일 크기, 개수, MIME type, 저장소, 썸네일 정책을 먼저 정한다.
- 영상은 별도 단계로 분리한다.
- 신고/관리자 숨김 정책이 미디어에도 적용되도록 한다.

### 6. 알림 기능 확장

현재 범위:

- 알림 설정은 존재한다.
- 실시간 알림은 미구현이다.

확장 후보:

- 좋아요 알림
- 신고 처리 상태 알림
- 서비스 공지 알림
- 알림 목록 화면
- 읽음 처리

주의:

- 실시간 push는 후순위로 둔다.
- 먼저 서버 저장형 알림 목록부터 구현한다.

### 7. moderation 운영 도구

현재 범위:

- 신고, 차단, 관리자 숨김을 위한 최소 API/상태가 있다.

확장 후보:

- 관리자 신고 목록
- 신고 상세
- 게시글 숨김/해제
- 사용자 닉네임 신고 처리 상태
- 반복 신고 남용 방지
- 운영자 메모

주의:

- 자동 moderation은 후순위다.
- 1차 운영은 사용자 신고 기반 수동 처리로 충분하다.

### 8. 외부 책 검색 및 import

현재 범위:

- 내부 DB 기반 책 검색과 상호작용은 구현되어 있다.

확장 후보:

- 카카오 도서 검색 연동
- 내부 DB 결과와 외부 검색 결과 병합
- ISBN13 기준 중복 확인
- 외부 책 선택 시 내부 `books` 저장
- 저장 후 기존 `READ`/`SAVE` interaction 흐름 재사용

주의:

- API key/env 변경이 필요하므로 구현 전 승인 대상이다.
- 신규 책의 교양 필터 초기 상태를 정해야 한다.
