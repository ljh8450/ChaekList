## 구현 완료로 보는 MVP 항목

### 책 탐색과 추천

- 홈 추천, 인기 책, 급상승 책, 카테고리별 랭킹
- 책 상세 정보
- 교양 필터 리포트
- 추천 근거
- 읽기 가이드
- 비슷한 책
- 내부 DB 기반 책 검색
- 책 상호작용
  - `READ`
  - `SAVE`
  - `UNSAVE`
  - `DISMISS`

### 온보딩과 마이페이지

- 관심 분야 선택
- 읽은 책 선택
- 독서 목적 1~3개 선택
- 마이페이지에서 관심 분야, 독서 목적, 읽은 책, 저장한 책, 추천 히스토리 조회
- 저장한 책을 읽은 책으로 전환
- 저장 취소
- 관심 없음 처리

### 개인 독서 성장

- `readingGrowth` 응답
- 월간 읽은 책 수
- 저장한 책 읽음 전환 수
- 카테고리 다양성
- 추천 전환 수
- 대표 배지 계산
- Header 대표 배지 표시
- SNS 활동 점수 보조 반영
- 모각독 인증 완료 기반 보조 점수와 배지 반영

### 통합 검색

- Header 검색 입력 연결
- 검색 결과 페이지
- 책 검색
- 키워드 검색
- 공개 게시글 검색
- 공개 유저 검색
- 최소 2글자 검색어 제한
- 비공개 게시글/비공개 프로필 미노출

### SNS 1차 기능

- 공개 feed
- 공유 게시글 생성
- 자유 텍스트 게시글
- 책 기반 공유 게시글
- 성장 카드 공유
- 모각독 공유 게시글
- 게시글 공개/비공개 전환
- 게시글 삭제
- 좋아요/좋아요 취소
- 좋아요 멱등성
- 공개 프로필 기본 조회
- 공개 게시글이 있는 유저의 공개 프로필 접근
- 공개 유저 검색
- 공개 유저 검색 가중치 보강
- 대표 배지 노출
- 배지 공개 설정 반영

### 설정과 개인정보

- 공개 설정
- 알림 설정
- 회원 탈퇴 진입
- 내가 작성한 글 보기
- 좋아요 누른 글 보기
- 비활성화 계정 공개 게시글 숨김
- 탈퇴 후 공개 게시글 투명화

### 최소 moderation

- 게시글 신고
- 사용자 닉네임 신고
- 사용자 차단
- 관리자 숨김 처리
- 숨김 게시글 feed/search/profile 제외
- 모각독 방 신고
- 모각독 방 관리자 숨김 처리
- 반복 게시 제한은 두지 않되 요청 멱등성 보장

### 모각독 MVP

- 전체 모각독 목록
- 책 상세 기준 모각독 목록
- 책 제목 검색 기반 모각독 생성/필터
- 모각독 방 상세
- 모각독 방 생성
- 참여/참여 취소
- 종료 후 인증
- 내 모각독 목록
- Social feed 공유 타입 연동
- 신고/관리자 숨김
- 시작 전/종료 후/새 참여자 저장형 알림

4. 관리자 moderation 화면/API 확장

낮은 우선순위:

1. 이미지 첨부

## 검증 계획

문서 변경만 수행한 경우:

- 빌드 검증은 생략한다.
- 문서 범위, 체크리스트 상태, 후속 명령 문구만 확인한다.

후속 backend 변경:

```powershell
cd backend
.\gradlew.bat test
```

후속 frontend 변경:

```powershell
cd frontend
npm run build
```
